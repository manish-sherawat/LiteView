# LiteView (NexusDocsViewer) - Future Enhancements & Visual Improvements

Here is a curated list of professional, modern, and sleek improvements to elevate the app's user experience. These suggestions focus on premium aesthetics and productivity, replacing the previous playful animations with sophisticated alternatives.

## 1. Transitions & Micro-Interactions
* Shared Element Transitions: Implement seamless hero transitions from the file thumbnail in the Dashboard directly into the full-screen PdfReaderScreen.
* Staggered List Entrance: When the dashboard loads or when switching tabs (All, Recent, Starred), list items should gracefully fade and slide in progressively (staggered animation).
* Context Menu Reveal: The file options menu (Share, Rename, Delete) should use a subtle scale-up and fade-in animation originating from the touch anchor point.
* Multi-Select Animation: When long-pressing a file to enter batch mode, smoothly shrink the file cards slightly and reveal selection checkboxes with a bouncy scale effect.
* Refined Page Transitions: Add a polished, subtle slide or soft crossfade when navigating between pages in the PDF reader.

## 2. Visual Improvements
* Material You / Dynamic Theming: Adopt Android 12+ dynamic colors so the app's primary accents automatically adapt to the user's system wallpaper.
* Glassmorphism (Blur) Effects: Apply a subtle background blur (acrylic effect) to the bottom action bars, sticky search headers, and dialog backgrounds for a premium feel.
* Professional Empty States: Implement high-quality, minimalistic, and static vector illustrations for empty states (e.g., a sleek folder icon with a magnifying glass for "No files found").
* AMOLED Dark Mode: Add an option for a "Pitch Black" dark mode to save battery on OLED screens, creating a stunning contrast with elevated dark-gray surface containers.
* Refined Skeleton Loaders: Enhance the shimmer effect to perfectly match the exact layout of the UI components (cards, text lines, icons) while storage is being scanned.

## 3. New Screens
* Comprehensive Settings Screen: Enhance the `SettingsScreen` to include options to clear thumbnail cache, set default views (List vs Grid), toggle themes, and manage app permissions.
* Detailed File Properties Screen: A rich bottom sheet showing comprehensive metadata (File Path, Exact Size, Creation Date, Page Count, Document Resolution).
* Folder & Tag Management: A new screen allowing users to organize documents into custom folders or assign color-coded tags (going beyond just a "Starred" list).
* Onboarding Flow: A sleek, 3-step introductory carousel for first-time users highlighting the PDF Reader, File Manager, and ML Kit Scanner capabilities.
* Cloud Backup Hub: A screen to connect services like Google Drive or Dropbox for automated syncing of scanned documents.

## 4. Core UX Enhancements
* Batch Actions (Multi-Select): Allow users to long-press to select multiple files in the dashboard to Share, Delete, or Tag them simultaneously.
* PDF Outline & Bookmarks: Add a side navigation drawer or bottom sheet in the PDF reader to view the document's table of contents and user-created bookmarks.
* Edge-to-Edge Display: Ensure the app draws behind transparent status and navigation bars seamlessly across all screens for a truly immersive experience.
* Text Extraction (OCR) Overlay: In the scanner review screen or PDF reader, allow users to tap a button to highlight and copy text directly from images using ML Kit Text Recognition.
