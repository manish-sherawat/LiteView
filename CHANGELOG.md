# Changelog

All notable changes to LiteView will be documented in this file.

## [1.4.7] - 2026-06-09
### Fixed
- **PDF Viewer:** Fixed an issue where the pinch-to-zoom functionality would fail to accumulate scale properly, causing the zoom to get "stuck".
- **PDF Viewer:** Fixed an issue where double-tapping the document would always zoom in (even if already zoomed in) instead of correctly toggling between zoomed-in and zoomed-out states.
- **Version Bump:** Updated application version to 1.4.7.
